# WaveBreaker-LYNX-Naval

WaveBreaker-LYNX-Naval: Space Engineers mod with modular aerospace/naval weapon systems. Includes: R-77 (MADDOG mode), KH-31AD/PH, R-27ER/ET, RBU-6000, ZirconLG, CIWS-30, Flare Dispensers, ECM systems, and weapon-specific ammo/config files. Focus on gameplay balance, not real-world fidelity.
